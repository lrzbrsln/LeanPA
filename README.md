This code formalizes the following statement:

Let ϕ be a sentence of second-order arithmetic. Then ϕ is true in the Werner's model of ZFC constructed inside Lean
iff ϕ, when interpreted as a propositional type in Lean, is inhabited.

The proof of the statement above is in LeanPA/main.lean.
The source at LeanPA/sets.lean is an implementation of the Werner's model of ZFC.
